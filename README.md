## Laravel-Form_testing

This repository was to test out many Laravel features and get a very in depth hands on experience on working in a project using many of the languages
in which I plan to use to make further projects, this was to practice essentially.

It features a database hosted on Postgres and features a built in leader board.

This project was to teach me the MVC architecture and working with the Eloquant ORM, along many other features such as seeders and factories.

This is the game I built inside of it, The way it works is that you are given a random number and using the grids show you can select one number from each
